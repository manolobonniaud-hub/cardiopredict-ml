# CardioPredict

Système de recommandation médicale basé sur le machine learning pour la détection de risques de maladies cardiovasculaires

## Fichiers
- groupe6versionfinalcardiopredict.py : application Streamlit (version finale du projet)
- Groupe6versionfinalCardioPredict.ipynb : développement du modèle et analyses
- coeur.csv : dataset principal
- coeur_jeunes_500_excel.csv : dataset complémentaire
- Exemple de resultats.pdf : des screenshots de résultats obtenus
- rapport_patient.pdf : le pdf pour le patient des résultats obtenus

## Comment exécuter le projet

Lancer l’application avec Streamlit (version récente recommandée) :

python -m streamlit run cardioprotect.py

### Prérequis
- Python 3.x
- Streamlit (version récente)  
  Installer / mettre à jour :
  pip install --upgrade streamlit
